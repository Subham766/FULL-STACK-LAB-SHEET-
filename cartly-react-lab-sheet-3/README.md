# Cartly React - Lab Sheet 3

This project implements the uploaded Lab Sheet 3 requirements:
1. Vite + React project
2. Product data exported from products.js
3. ProductCard with props
4. ProductList using map() and product.id as key
5. Cart state in App using useState and addToCart passed through props
6. Cart component with quantity, subtotal and grand total
7. Cart show/hide state with navbar count badge
8. CheckoutForm with controlled inputs for Name, Address, Pincode, Phone and Payment Method
9. Conditional rendering for an empty cart

## Run
npm install
npm run dev

## Note
Product images are remote Unsplash URLs, so internet access is needed for the images to load.
