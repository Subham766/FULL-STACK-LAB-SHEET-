# Lab Sheet 4 - Node.js

Complete code for all 12 tasks of BTCS303P-AS05.

## Tasks
1. Custom Modules
2. File System CRUD
3. Directory Operations
4. Path Module
5. OS Module Report
6. Events / EventEmitter
7. HTTP Server with Manual Routing
8. Query String Parsing
9. Reading a Large File with Streams
10. npm + nanoid
11. Command-Line Arguments Calculator
12. Environment Variables

## How to run
Open a terminal inside the required task folder and run the JavaScript file with Node.js.

Examples:
- Task 1: `node app1.js`
- Task 2: `node file-ops.js`
- Task 3: `node dir-ops.js`
- Task 4: `node path-demo.js`
- Task 5: `node sys-report.js`
- Task 6: `node order-events.js`
- Task 7: `node server.js`
- Task 8: `node server.js`
- Task 9: `node stream-demo.js`
- Task 10: `npm install` then `node id-gen.js`
- Task 11: `node calc-cli.js 10 5 +`
- Task 12 (Windows CMD): `set PORT=5000 && node env-demo.js`
